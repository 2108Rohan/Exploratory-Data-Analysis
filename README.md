# Data Analysis Projects Portfolio

Welcome to my Data Analysis portfolio repository! This repository consolidates **6 individual data analysis projects** focusing on Exploratory Data Analysis (EDA) using Python, Pandas, and Jupyter Notebooks.

Each project contains a Jupyter Notebook detailing the code, analysis, and visualizations, along with its corresponding CSV dataset.

## How to Get Started

### Prerequisites
Make sure you have Python 3 and the following libraries installed:
- `pandas`
- `numpy`
- `matplotlib`
- `seaborn`
- `jupyter` / `notebook`

You can install the dependencies via pip:
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Running the Notebooks
1. Clone the repository.
2. Navigate to any project folder.
3. Open a terminal and start the Jupyter Notebook environment:
   ```bash
   jupyter notebook
   ```
4. Open the `.ipynb` file in your browser and run the cells.
